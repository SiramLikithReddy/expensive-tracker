# Python Practice Projects

A collection of Python projects built while learning core concepts — OOP, error handling, and file I/O.

## Projects

### expenses_tracker.py
Command-line app that tracks monthly expenses by category and calculates savings.

### student-percent.py
Class-based student grade manager — calculates total, percentage, and letter grade for multiple students, then ranks them by performance.

### car.py
Simple OOP practice — a Car class with attributes and a fuel-tracking method, including input validation.

### contact-book.py
Class-based contact manager — stores a contact's details, dials a number with input validation, and saves contact info to file.

## How to run
Each file can be run independently:

python filename.py
